# 墨线漫画主题（Ink panel）

把 DeepSeek Harness 的界面换成分格漫画 / 连环画的纸上观感：墨黑描边、硬投影、网点纸底与朱红印章色。自带**宣纸**与**夜墨**两套纸色。

## 两套纸色

- **宣纸（day）**：米黄纸 `#f4ecdc`、墨 `#171310`、朱印 `#c2382b`，配靛蓝、藤黄、竹青作状态色。
- **夜墨（night）**：提灯夜读——纸面变成 `#14110e` 的墨底，原先的墨色反过来成为 `#f2e9d8` 的米白线条，朱印提亮成 `#e05a45`，靛蓝 / 藤黄 / 竹青同步提亮。
- 两套纸色不是反色滤镜：线宽、投影、网点透明度、纸面渐变都各自调过，深色下仍然是「印在纸上的画」，而不是发光的深色面板。

## 怎么开关、怎么换纸色

两处入口，同一份状态：

1. **设置 → 通用** → 「墨线漫画主题」一行：左侧开关，右侧三段选择器「跟随外观 / 宣纸 / 夜墨」。
2. 输入框下方的「墨」印章按钮：一点即开关；标题里会显示当前生效的纸色。

- **跟随外观**：优先读界面自身的深色标记（`body[data-ds-dark-theme]`），取不到时回退到系统 `prefers-color-scheme`，并在两者变化时实时跟随。
- 状态存在当前浏览器的 localStorage：`dsh.ink-panel.enabled`（`on` / `off`）与 `dsh.ink-panel.mode`（`auto` / `day` / `night`）。
- 关闭后主题立即移除，内置外观（浅色 / 深色）原样恢复。

## 它改变了什么

- **整站配色**：桥接约 160 个内置 `--dsw-*` 设计令牌，把纸张、墨色、朱印色映射到背景、文字、描边、按钮、菜单、提示、状态色与代码高亮。
- **表面与结构**：侧栏加双线边框与网点底；会话气泡变成分格面板（双线框 + 硬投影）；输入框卡片、对话框、菜单、浮层共用一套「印刷框线」。
- **文字排版**：标题用宋体并加朱红侧杠；正文链接加红色下划线、悬停染藤黄；代码块、表格、引用、键帽、分隔线各有独立处理。表格单元格留出内边距与行距，长表格不再贴边。
- **交互细节**：焦点环改成朱红虚线（出血线感）；滚动条墨色、悬停转朱红；选中文字是半透明藤黄。
- **不改布局**：只改颜色、边框、阴影、圆角与一像素级的视觉元素，不动任何尺寸、间距与 DOM。

## 设计约束

- **颜色只有一个来源**：`src/styles/00-palette.css`。day 值定义在 `:root`，night 值重定义在 `html[data-dsh-ink][data-dsh-ink-theme='night']`；其余样式片段里没有一处字面量颜色（`scripts/check.mjs` 会断言这一点）。
- **透明度走通道三元组**：`rgb(var(--ip-ink-rgb) / 34%)`。换纸色时 ink / paper 的 RGB 互换，所有淡色、网点与投影自动反向，不需要第二套规则。
- 不加载网络字体与外部图片，纹理由 CSS 渐变绘制（网点、虚线、硬投影）。
- 所有规则挂在 `html[data-dsh-ink]` 之下，卸载样式表或切换开关即可完全还原。
- 选择器同时兼容 CSS Modules 的类名后缀形态（`_card`、`_sidebarCol` 等）与数据属性挂点（`[data-composer-seat]`、`[data-message-bubble]`），避免依赖内部实现细节。

## 兼容性

- DeepSeek Harness 0.2.x，在 0.2.2-rc.3 上开发与验证。
- 桌面端与 Web 端同一份客户端产物。

## 卸载

在「插件」页移除 `dsh-ink-panel` 后刷新界面；它在浏览器里没有留下除两个 localStorage 键以外的任何状态。
